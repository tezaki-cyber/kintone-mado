# BCR キントーン機能の窓口

キントーン(BCR_商品管理表 ほか)に足す機能を、1本の窓口から読み込むための置き場です。
キントーン側に登録するのは次の2つだけで、機能を足す・直すときに登録を変える必要はありません。

1. `mado-config.js` … 合言葉のファイル(ファイルで登録。ここには置かない・GitHub に上げない)
2. `mado.js` … 窓口(アドレスで登録)

## 機能を足す・直す
- 機能は `features/名前.js` に置き、`mado.js` の `FEATURES` に1行足す。
- 機能の側は `BCR_MADO.feature('名前', { 'app.record.index.show': function (ev) { … } })` で登録する。
- 直したら `mado.js` の `VERSION` を変える(古い読み置きを使わせないため)。
- 止めたいときは、その機能の `on` を `false` にする。

## 決まり
- 合言葉・鍵・商品のデータは、このフォルダに入れない(公開の場所に置くため)。
- 使う人の体験が大きく変わる改変、スプレッドシートからの定期更新を壊す改変はしない。
- 機能は専用の一覧・ボタン・小窓で足す。今ある一覧や入力の流れは変えない。
- 窓口や機能が読めないときは黙る(キントーンのふだんの画面を止めない)。

## いま入っている機能
| 名前 | アプリ | 出る場所 | 中身 |
|---|---|---|---|
| fukushizai | BCR_商品管理表 | 一覧「副資材・カートン」 | カートンマークの自動生成(生成は `fukushizai/` のサーバー) |

## 手元で試す
`fukushizai/dev/dev_server.py`(ポート5196)のまね画面が、このフォルダの `mado.js` と `features/` をそのまま読みます。
